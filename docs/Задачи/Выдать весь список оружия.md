# Выдать весь список оружия

Статус: выполнено, принято пользователем 2026-11-25; проверка безопасности и итоговая документация выполнены.

## Цель и границы
В GM Shop → Weapons рядом с числом предметов каждой категории добавить кнопку выдачи всего соответствующего мультиселла в инвентарь самого администратора. Выбранная цель не получает предметы. Обычная покупка остаётся доступной по прежней ссылке.

## Ожидаемое поведение
- Кнопка All выдаёт продукты всех строк указанного GM-списка, а не только первой страницы мультиселла; количества берутся из production. По уточнению пользователя всё оружие выдаётся с заточкой +16; щиты и прочие неоружейные предметы сохраняют исходную заточку.
- Исправить раскладку страницы по скриншоту: количество и All должны находиться в одной строке в отдельных ячейках. Сохранить компактные строки и доступ ко всем категориям.
- Выдача является административным созданием без списания ингредиентов. Проверять право admin_buy, префикс gm_weapon_, adminOnly и отсутствие NPC-привязки.
- До выдачи проверить весь набор: корректность шаблонов, количеств, суммарный вес, свободные места и переполнение стопок. При ошибке не начинать выдачу.
- Не выдавать во время обмена/магазина. Отправить отчёт и вернуть страницу Weapons.

## Критерии приёмки и проверки
- Сверить кнопки с XML-списками и числами предметов.
- Проверить обработку полного списка более 40 строк, нескольких продуктов, количества и заточки.
- Проверить запрет обычных мультиселлов, некорректных параметров и доступа без прав, а также отказ при нехватке места/веса.
- Собрать сервер, установить и проверить загрузку; пользователь проверяет получение предметов в игре.

## Предположения
- Одна выдача означает один проход по строкам мультиселла, без дополнительного множителя и автоматического сохранения настроек свечения.
