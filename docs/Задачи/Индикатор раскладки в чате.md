# Индикатор раскладки в чате

- Цель — устранить чёрный квадрат слева от текста в строке ввода.
- Границы — клиентский интерфейс чата.
- Ожидаемое поведение — отображение текущей раскладки по образцу High Five, если клиент поддерживает такой индикатор.
- Приёмка — для EN и нераспознанных раскладок показывается английский значок, текст вводится как прежде.
- Проверки — сравнение ресурсов и логики High Five, проверка поставки и визуальная проверка в игре.
- Ограничение — Interlude не возвращает отдельный код RU. Поддержка отдельного флага RU потребует изменений нативного кода клиента.

## Реализация

Обработчик ChatWnd.HandleIMEStatusChange использует штатный значок L2UI.ChatWnd.IME_en для неизвестной раскладки, чтобы убрать чёрный квадрат. Клиент загружает исправление из system/interface.u при запуске.

Проверены текстура, сборка, импорты и контрольные суммы. Имя текстуры фиксировано и не зависит от вводимого текста.
