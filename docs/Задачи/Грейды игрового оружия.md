# Грейды игрового оружия

Цель — сравнять боевые характеристики оружия одного типа и грейда и дать выбрать его внешний вид на любом грейде от исходного до S.

- Область — экипируемое игроками оружие из серверного каталога. Исключения — оружие питомцев, NPC, Infinity, удочки и ивентовое оружие. Щиты входят в задачу отдельным типом с той же лестницей до S. Проверить границу по серверным шаблонам и категориям GM Shop.
- Сохранить ID и исходный грейд оригиналов. Добавить отдельный ID на каждый более высокий грейд по лестнице NG → D → C → B → A → S. Вариант получает внешний вид оригинала и профиль целевого грейда.
- Обновить серверные шаблоны, клиентское отображение и GM Shop. Предлагаемый интерфейс — выбор грейда и существующая группировка по типу и назначению, штатная бесплатная покупка и выдача категории +16.
- Приёмка — сверить полноту охвата и исключения, уникальность ID, совпадение серверного и клиентского грейда, боевые профили, покупки и выдачу через GM Shop. В клиенте проверить открытие списков, отображение и экипировку вариантов.

Использовать существующее деление оружия по типам. Для каждой пары типа и грейда выбрать топовое оружие среди исходных предметов этой пары. Применить его боевые характеристики ко всем оригиналам этой пары и ко всем копиям, создаваемым для неё. Состав эталонов определить до изменения шаблонов.

Проверка эталонов — вывести исходный ID и характеристики победителя для каждой пары типа и грейда до генерации вариантов.

Пример приёмки — меч B сохраняет свой ID, название, текстуры и грейд B, получает боевые характеристики топового меча B. Копии A и S получают отдельные ID, то же название и текстуры, характеристики топовых мечей A и S соответственно. Все три доступны в админ-магазине. Исходный меч S получает профиль S без создания копии.

## Уточнение интерфейса магазина

На входе сразу показать категории NG. Грейды разместить в одной строке кнопок и выделять активный. Щиты показывать в списке каждого грейда. Остальные специальные категории вынести на отдельную страницу с прямым переходом с каждого грейда. Приёмка — проверить все переходы, сохранение действий Buy и All и читаемость в игровом окне. Для отдельных правок HTML достаточно `//reload htm`. Смена характеристик существующих щитов требует рестарта.

Приёмка щитов — внутри каждого грейда в GM Shop должен быть один щит на набор клиентских текстур. Совпадение между грейдами допустимо. При дубликате проверить привязки ID перед удалением.

Уточнение проверки — учитывать ресурс модели и текстуры щита в полях drop_mesh и drop_tex. При совпадении оставить один вариант на грейд в витрине; ID уже выданных экземпляров сохранять.
