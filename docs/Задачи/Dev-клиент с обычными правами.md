# Dev-клиент с обычными правами

Цель — проверить управление игрой и редактором через Computer Use в пользовательском сеансе Windows.

- Создать отдельную копию клиента для dev-запуска и ярлык для редактора. Оба процесса должны работать с правами обычного пользователя.
- Сохранить действующие ярлыки, рабочий клиент и настройки оружия. Системные параметры Windows не менять.
- Проверить манифест копии, цель ярлыка и запуск редактора с подключением к игре.
- Критерий проверки ввода — переключается «Крупный шаг», открывается инвентарь, после экипировки одного кинжала видны правильный ID и изменение свечения.
- Открытый вопрос — примет ли игра ввод при одинаковых правах. Итог требует проверки в игровом сеансе.

Промежуточная проверка — запущен L2DevUser.exe через отдельный ярлык, редактор подключился. Клики переключают «Крупный шаг» и открывают инвентарь. Макрос в первой ячейке открыл админку; обе кнопки All выдали 26 и 6 кинжалов. Hell Knife +16 определён как ID 243, изменение размера вызвало пересоздание эффекта, затем выполнен сброс к 1.0. Сохранение не выполнялось. Управление камерой пока требует проверки — колесо прокрутило инвентарь при указании точки в игровом мире.
