# Русификация системных сообщений клиента

- Цель — пробно перенести русские системные сообщения из установленного клиента 4Game.
- Границы — менять только проверенные фразы нашего клиента. Клиент 4Game используется для чтения.
- Поведение — проверять смысл, назначение и параметры каждой фразы. Совпадения ID недостаточно.
- Приёмка — пробный клиентский DAT содержит проверенные переводы, прочие записи и поля сохранены.
- Проверки — сравнить записи после обратного чтения DAT, затем проверить сообщения в игре.
- Предположение — пробная партия из однозначных и часто встречающихся сообщений.
- Открытый вопрос — доступность английской таблицы той же версии 4Game.

## Продолжение

- Проверить всю таблицу Interlude и подготовить построчный отчёт: исходный текст, вариант 4Game, решение и причина.
- В пробный DAT включить только вручную подтверждённые замены с совместимыми параметрами. Остальные строки оставить для чтения в отчёте.
- Проверить обратное чтение DAT и сохранность остальных полей.

## Смысловые расхождения

- Цель — выделить подтверждённые изменения события, условий или действующего лица.
- Границы — только отчёт по совпадающим ID Interlude и 4Game. DAT не менять.
- Приёмка — для каждого случая указать обе фразы, смысловое различие и назначение в Interlude, если оно известно.
- Проверка — сверить строки с обеими таблицами. Открытых вопросов нет.

## Полный перенос

- Перенести тексты 4Game по совпадающим ID. В 31 строке из отчёта сохранить исходные числовые условия, если они различаются.
- Сохранить параметры движка, структуру и служебные поля DAT. Записи без пары оставить в исходном виде.
- Приёмка — пробный DAT и построчный отчёт об исключениях и адаптациях. Проверка — обратное чтение и сравнение с исходной таблицей.

## Установка для проверки

- Установить полный пробный DAT в client/build/system и сохранить исходник в backups.
- Проверить совпадение контрольных сумм поставленного файла и пробного DAT. Приёмка в игре — загрузка клиента и отображение системных сообщений.

## Восстановление запуска

- После ошибки с Ver111 вернуть исходный Ver413 и сверить SHA-256 с резервной копией. Перевод сохранить отдельно.

- Добавить пробный DAT в папку клиента под отдельным именем и сверить SHA-256 обеих версий.

- Для повторного теста активировать пробный DAT по запросу пользователя. Перед заменой и после неё сверить SHA-256.

## Исправление упаковки

- Воспроизвести причину ошибки запуска и подготовить новый DAT с проверяемой упаковкой. Перевод сохранить. Приёмка — обратное чтение, установка и запуск игры; открытый вопрос — поддерживаемый клиентом ключ упаковки.
