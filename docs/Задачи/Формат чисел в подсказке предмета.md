# Формат чисел в подсказке предмета

Цель — повысить читаемость чисел в подсказке. Расход обоих видов зарядов отображается как X1, без пробела. Разряды характеристик, веса и уровня заточки группируются обычным пробелом. Даты и текст описаний вне области правки.

Приёмка — собрать interface.u и проверить в клиенте оба вида зарядов, итоговую и базовую атаку, бонус, защиту, вес и заточку. Открытых вопросов нет.

Подсказка группирует цифры по три. Пример — 80 219 (245 +79 974). Для применения нужен обновлённый клиентский interface.u.
