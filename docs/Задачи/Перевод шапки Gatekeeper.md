# Перевод шапки Gatekeeper

Цель: перевести заголовки таблиц на русский для понятного интерфейса.
Границы: только атрибуты header в gatekeeper.xml, без изменения логики и размеров.
Ожидаемое поведение: Location → Локация, Capital → Столица, Point → Точка, Price → Цена, Item → Валюта, Level → Ур.
Критерии приёмки: русская шапка во всех четырёх таблицах; корректное отображение в клиенте.
Проверки: разбор XML, 20 заголовков, отсутствие изменений остальных данных; визуальная проверка пользователем.
Открытые вопросы: нет.
