# Дуалы с одинаковыми текстурами

## Цель и границы

Очистить ассортимент одного мультиселла gm_weapon_dual_lrhand_physical. Оставить дуалы с одинаковой текстурой обеих моделей. Удалить выбранные ID и их ссылки по процедуре очистки каталога оружия.

## Поведение и приёмка

- Сравнить ссылки wpn_tex[0] и wpn_tex[1] из рабочей таблицы клиента без учёта регистра.
- Удалить только несовпадающие пары исходного мультиселла из клиентских таблиц, шаблонов и связанных источников выдачи. Сверить сохраняемые ID.
- Провести миграцию связанных данных по предыдущей схеме с резервной копией и пробным прогоном.

## Проверки

Проверить обратную сборку DAT, серверные ссылки, запуск GameServer и ассортимент мультиселла в клиенте.

## Открытые вопросы

Состав ссылок и наличие экземпляров удаляемых ID определяются при аудите.
