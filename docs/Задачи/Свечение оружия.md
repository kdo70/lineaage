# Свечение оружия

Статус: выполнено, принято пользователем 2026-11-25; проверка безопасности и итоговая документация выполнены.

## Цель и границы
Оставить у обычного оружия эффект LineageEffect (c_u006 и аналогичные), удалить LineageWeapons.rangesample. Требование исправлено пользователем. Сохранить ретейльные эффекты Akamanah, Zariche и Infinity. Создать инструмент настройки положения оставшегося свечения в работающем клиенте и простой запуск двух режимов ярлыками.

## Ожидаемое поведение
- В dev-режиме сочетания клавиш изменяют положение свечения без перезапуска клиента; доступны сохранение и сброс.
- Экипированное оружие определяется автоматически у своего персонажа, без ручного выбора ID.
- Каждая пара клавиш перемещает эффект в обе стороны; парные эффекты изменяются зеркально.
- Исправить отсутствие видимого изменения эффекта в текущей версии инструмента; проверить обновление созданного эффекта, а не только его исходных данных.
- Добавить уменьшение и увеличение размера эффекта сочетаниями клавиш; размер сохраняется и сбрасывается вместе с позицией, у парного оружия меняется синхронно.
- Для оружия без эффекта определить соответствие по эффектам высоких грейдов, типу и модели оружия и назначить недостающий эффект. Существующие эффекты, ретейльные исключения и сохранённые настройки не менять. Щиты, удочки и оружие питомцев не включать автоматически в подбор обычного оружия.
- Заменить Alt-комбинации на Ctrl+Shift с прежними буквенными клавишами; крупный шаг включать в окне инструмента. Проверить новую обработку модификаторов.
- Сохранённые настройки привязаны к оружию и пригодны для последующего переноса в клиент после настройки всего каталога.
- В текущей сессии каждое ручное изменение и сохранение обновляет кэш по имени эффекта. При экипировке оружия с этим эффектом переносить XYZ и размер; собственную скорость частиц оружия сохранять. Кэш сессии хранить отдельно от постоянных настроек по ID, при новом запуске начинать новую сессию.
- Для парных эффектов переносить зеркальные координаты. Общий кэш имеет приоритет над прежним черновиком оружия, чтобы использовалась последняя настройка эффекта.
- Сброс немедленно возвращает исходные значения текущего оружия, обходит общий кэш и сохраняет этот сброс для него до следующего ручного изменения в текущей сессии. Сброс не заменяет общий кэш значениями этого оружия и не меняет настройки других предметов.
- Обычный и dev-режимы запускаются отдельными ярлыками без ручных команд.
- Старая реализация используется только после проверки применимости: она настраивала другой эффект, EnchantGlow.
- Старый проект и исходные артефакты доступны только для чтения; инструменты находятся в tools.

## Критерии приёмки и проверки
- Проверить состав эффектов всех строк weapongrp и неизменность исключений.
- Проверить обратную сборку DAT и сохранность остальных полей.
- В игре проверить изменение положения, сохранение, сброс и переключение оружия, включая парное.
- Проверить запуск обоих режимов ярлыками и отсутствие управления свечением в обычном режиме.
- Проверить сохранения и их воспроизведение после перезапуска; фактический перенос в DAT оставлен для отдельной задачи по последнему указанию пользователя.
- Подготовить резервные копии изменяемых файлов.

## Открытые вопросы и предположения
- Рабочий клиент подтверждён: D:\Lineage\client\build.
- Сброс возвращает исходные значения текущего оружия. Раскладка клавиш выбирается при реализации; сохранение — по ID.
- Live-настройка должна обслуживать EnchantedEffect; ранее подготовленные значения rangesample нельзя применять к нему. Отражение парных эффектов проверить на модели в игре.
- Обновление должно быть немедленным; переэкипировка допустима только при отсутствии другого варианта. Перезапуск клиента для настройки недопустим.
