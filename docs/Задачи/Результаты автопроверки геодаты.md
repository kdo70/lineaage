# Автопроверка маршрутов по геодате

Проверены 139 файлов L2J, включая тестовый 19_21. Из 372 835 смоделированных щелчков прямой путь был закрыт для 185 535. В 50 470 случаях продвижение составило меньше 16 единиц. Для 116 из них в 69 регионах найден проверенный путь до метки через одну промежуточную точку. Во всех 116 случаях персонаж немного продвинулся.

[Маршруты](Геодата-маршруты.csv) содержат координаты старта, метки и промежуточной точки. Последний столбец — продвижение исходного алгоритма по горизонтали в мировых единицах с округлением. [Сводка](Геодата-регионы.csv) содержит число проверок и найденных случаев по каждому квадрату.

Для повтора запустить python tools/run_region_audit.py из D:\Lineage с собранным сервером. Выборка воспроизводима и чаще проверяет клетки с ограничениями направлений. Сравнивается статическая геодата и обработчик запасного маршрута. Клиентские коллизии, двери, покадровое движение и все возможные высоты одной клетки требуют отдельных проверок.

После добавления локального обхода повтор той же выборки дал 0 случаев остановки с найденным контрольным путём. [Повторная сводка](Геодата-регионы-обход.csv) и [список маршрутов](Геодата-маршруты-обход.csv) относятся к этому прогону до последующей правки ступеней.
