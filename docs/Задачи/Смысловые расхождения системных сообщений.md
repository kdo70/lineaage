# Смысловые расхождения системных сообщений

Сопоставлены текущий systemmsg-e.dat Interlude и SystemMsg-ru.dat 4Game. В отчёт включены вручную выделенные случаи, где замена меняет событие, объект, условие или действие игрока. Название константы показывает назначение ID на сервере и помогает выявить неточности текущей локализации.

Отчёт содержит подтверждённые различия текстов. Фактические настройки сервера по одному сообщению определить нельзя. Список не исчерпывает все пары из общей сверки.

## ID 68

- Interlude — Выйти из Клана $s1. Вы уверенны?
- 4Game — Выйти из клана $s1? После этого нельзя вступить в другой клан в течение 24 ч.
- Различие — 4Game добавляет запрет на вступление в другой клан на 24 часа.
- Константа сервера — `WOULD_YOU_LIKE_TO_WITHDRAW_FROM_THE_S1_CLAN`

- Различие — 4Game добавляет запрет на приём новых участников на 24 часа.
- Константа сервера — `WOULD_YOU_LIKE_TO_DISMISS_S1_FROM_THE_CLAN`
