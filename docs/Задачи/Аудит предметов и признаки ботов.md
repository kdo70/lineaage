# Аудит предметов и признаки ботов

Статус — предложение к обсуждению, 2026-11-25.

## Цель и границы

Подготовлен проект проверок, чтобы GM мог восстановить происхождение ценностей и разбирать признаки автоматического фарма. В рабочем конфиге выключены `LogItems` и `GMAudit`. Штатный `Inventory.addUpdate` пишет только нескладываемые предметы. Ниже предложен объём первой версии.

## Ожидаемое поведение

- Начать с адены и выбранных ценных предметов. Для них учитывать начальный остаток и все источники, передачи и списания, включая лавку, склад, налоги и GM-команды.
- До выдачи сервер проверяет основание, получателя и количество. Для разовой награды выдача и отметка о её получении должны сохраняться вместе, включая повтор запроса и перезапуск.
- Для завершённой операции сохранять серверное время, общий ID операции, основание (например, конкретную награду), участников, контейнеры, тип и при необходимости экземпляр предмета, количество до и после. Периодически сверять журнал с сохранёнными остатками. При пропуске данных сообщать о неполноте аудита.
- Для поиска ботов собирать по интервалам время активного боя, убийства, перемещения между зонами и передачи добычи. Сочетание признаков выносить на проверку GM с периодом, числами и связанными событиями. Отдельно учитывать штатные автоатаки, группу и офлайн-лавку.

## Критерии приёмки и проверки

- По тестовой цепочке «награда → обмен → склад» восстанавливаются источник, получатель и остатки. Обычные расходы, торговые сборы и выдача GM объясняются записями.
- При повторной обработке разовой награды начисление одно. На подготовленной выборке расхождение с остатком попадает в отчёт, пропуск журнала помечается отдельно.
- На записях обычного фарма и офлайн-лавки одно длительное подключение не вызывает подозрения. На тестовой серии с несколькими признаками GM видит основания для проверки.
- На тестовой нагрузке измерить объём записей в сутки и задержку игровых операций, проверить ротацию и обработку пропусков.

## Открытые вопросы

Согласовать перечень ценностей, срок хранения, допустимую нагрузку и правила сервера для макросов и нескольких окон. Пороги для поведенческих сигналов подобрать по наблюдениям за обычной игрой.
