# Массовая настройка иконок оружия с ЛС

Цель — для обычного инкрустируемого оружия C–S показывать отдельную иконку с ЛС. Использовать штатную i01 по образцу Phantom Sword. Для оставшихся общих рисунков подготовить тёплый вариант 32×32 из основного рисунка. Сохранить существующие рабочие ссылки, иконки без ЛС и серверное поведение. Проверки — полный охват, совпадение ссылок с пакетом, обратная сборка и переключение в игре. Исключены специальные категории и предметы, недоступные для инкрустации.

Уточнение после проверки — у Dasparion's Staff 4904 и 4905 использовать штатную пару i00 → i01. У трёх общих текстур проверить свечение вокруг силуэта по сравнению со штатными 85, 82 и 139. Проверить пиксели 32×32 до установки.

Критерий визуальной приёмки трёх общих иконок — сравнить PNG 32×32 с парами Arcana Mace и Phantom Sword. Ореол должен следовать контуру оружия, сохранять детали клинка и оставлять углы тёмными.

Для следующего превью измерить профиль свечения по штатной паре Arcana Mace и перенести его на три общих рисунка. Проверить PNG до установки.

Установить три принятых изображения из художественного превью. Вырезать ячейки, привести к 32×32, проверить декодированные DXT1 и заменить три экспорта в текущем клиентском пакете. Проверить ссылки DAT и хеши установленных файлов. Серверных изменений нет.

Расширить охват на все грейды серверного оружия персонажа. Исключить ивент, Infinity, оружие монстров, питомцев и удочки. Сохранить корректные пары, подключить подходящие штатные иконки, создать недостающие и установить клиентский пакет. Проверить ссылки и исключения, декодированные текстуры 32×32 и запуск клиента. Для предметов с серверным запретом аугментации проверяется клиентская ссылка.

## Результат

Для 1425 ID обычного оружия настроены отдельные иконки с ЛС. Используются штатные альтернативы и четыре новые текстуры 32×32 DXT1 для Bouquet, Heavy Sword, Zweihander и парных мечей. Для Cursed Maingauche и Dasparion’s Staff восстановлены обычные иконки без свечения.

В клиентскую поставку входят systextures/Icon.utx и system/weapongrp.dat. Для применения нужны оба файла и перезапуск клиента. Проверены ссылки, обратная сборка и запуск с установленными файлами. Серверные ограничения аугментации действуют по-прежнему. Переключение всей партии предметов в игре не проверялось.
