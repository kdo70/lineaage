# Очистка локальных изменений

## Цель и границы
Восстановить шапку «Сборки сервера», убрать изменения без содержательного diff и исключить локальные настройки Obsidian из Git. Локальные настройки сохранить на диске.

## Ожидаемое поведение и критерии приёмки
Шапка соответствует HEAD; ItemIconData.java и три документа без содержательных изменений восстановлены. docs/.obsidian/ игнорируется. В статусе остаются только изменения этой задачи.

## Проверки
Проверить diff до восстановления, git status, git check-ignore и git diff --check.
