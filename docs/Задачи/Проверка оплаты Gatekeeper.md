# Проверка оплаты Gatekeeper

- Цель — сразу сообщать о нехватке валюты, чтобы игрок не ждал анимацию при отказе.
- Границы — платные направления GlobalGatekeeper. Цена рассчитывается по действующим правилам. Списание остаётся в момент завершения телепорта.
- Приёмка — при нехватке валюты сообщение приходит сразу, без анимации, шкалы и блокировки движения. При достаточном балансе телепорт работает штатно. При нехватке валюты к концу задержки перенос отменяется.
- Проверки — сборка, smoke-проверка Gatekeeper и игровые сценарии с недостаточным и достаточным балансом.
- Открытых вопросов нет.
