# Приоритет позиций свечения

## Цель и границы

Выбирать настройки по ID экипированного оружия в дев-редакторе. Формат и пользовательские записи сохраняются.

## Поведение и приёмка

- При экипировке использовать effect-positions.json, при отсутствии записи — catalog.json.
- Сброс сразу применяет значения catalog.json к текущему ID.
- Принятый порядок: сброс действует до конца сессии, кнопка «Сохранить» закрепляет результат между запусками. Несохранённые ручные правки теряются при смене оружия.

## Проверки

Проверить оружие с записью и без неё при общем эффекте, сброс, повторную экипировку и новый запуск. Визуальная проверка в клиенте при приёмке.
