# Иконки экипированных дуалов

## Цель и границы

Исправить иконки парных мечей в обеих ячейках оружия инвентаря. Проверить все шаблоны дуалов, включая варианты с ЛС.

## Поведение и приёмка

При экипировке обе ячейки показывают текущий дуал с подходящими иконками. При смене и снятии оружия ячейки обновляются. Подсказка и управление предметом работают в обеих ячейках.

## Проверки

Найти источник общего изображения, сверить все шаблоны и проверить сборку клиента. В игре проверить смену разных пар, дуалы с ЛС и переход на одноручный меч со щитом.

## Открытые вопросы

Отдельные иконки клинков зависят от наличия клиентских ресурсов для обеих рук.

## Реализация

В клиентском weapongrp.dat настроены иконки правой и левой руки для 151 дуала по модели и текстуре каждого клинка, включая набор с ЛС. Это устраняет подстановку иконки чужого меча при экипировке. Проверены 159 записей типа DUAL. Обратное чтение DAT подтвердило изменения только в четырёх полях иконок затронутых пар. Для применения нужен перезапуск клиента.
