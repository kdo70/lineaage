# Русификация SysString

- Цель — перенести интерфейсные строки 4Game в sysstring-e.dat Interlude.
- Границы — только рабочий клиент. Исходник сохранить для отката.
- Поведение — сверить назначение строк и параметры. При расхождении чисел сохранить условия Interlude. Строки без пары и с другим назначением оставить исходными.
- Приёмка — новый DAT и построчный отчёт. Проверки — структура, обратное чтение Ver413, CRC32 и совпадение установленного файла.
- Предположение — совпадение ID используется для поиска пары, а применимость определяется по тексту.
- Открытые вопросы — отображение строк в интерфейсе игры.

## Выбор пользователя

- Применить варианты 4Game для ID 25, 61, 110, 194, 195, 338, 390, 598, 637, 910, 925, 999, 1000, 1027, 1190, 1209. Сохранить сочетания клавиш Interlude.
- Проверить, что изменения относительно предыдущего DAT затронули только выбранные ID, и обновить отчёт.

## Подписи окна статуса

- Вернуть исходные подписи ID 102 (PvP/PK) и 709 (Очки). Проверить, что изменились только эти строки и PvP/PK снова относится к паре счётчиков. Открытых вопросов нет.

## Компактные подписи настроек

- Сократить подписи ID 207, 213, 464, 486, 1472. В поле языка показывать «Русский», сохранив код локали и текущую загрузку DAT.
- Проверить точные изменения строк, сборку Interface.u и установку с резервными копиями. Открытый вопрос — визуальная проверка в игре.

- Для отмеченного пункта ID 927 использовать полное слово «Прозрачность». В списке языка меняется только видимая подпись.

- Развернуть значения качества ID 224–226 и 1233–1237 на вкладке «Видео».

- После проверки в игре сократить ID 435 до «Имена» и ID 927 до «Прозрачн.». Проверить, что изменились только две подписи.

- По уточнению пользователя восстановить полную подпись «Фильтр текстур» (ID 464). Проверить, что остальные строки сохранены.

- Развернуть подпись ID 370 до «Минимальные настройки». Проверить, что изменился только этот ID.

- Чтобы «Минимальные настройки» поместились в одну строку, расширить только FrameBox и предел ширины его подписи. Проверить точный diff XDAT. Визуальная проверка после перезапуска.

## Понятные подписи на трёх вкладках

- Уточнить подписи дальности, лимита персонажей, частоты и снимков, двух типов озвучки и игровых переключателей по их привязкам. Сохранить расположение и работу настроек.
- Проверить новые формулировки, список изменённых ID, упаковку и установку DAT. Открытый вопрос — размещение текста в игре.

## Трофеи и ширина подписей

- Использовать подпись и пять вариантов High Five для распределения трофеев. Сохранить ID и порядок вариантов. Расширить строку управления в GameTab.
- Исправить выход подписей за левый край на вкладке «Видео». Проверить точечные изменения DAT и XDAT, затем отобразить в игре.
