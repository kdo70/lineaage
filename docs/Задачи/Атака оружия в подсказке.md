# Атака оружия в подсказке

## Цель и границы

Показать вклад заточки в физическую и магическую атаку в клиентской подсказке оружия. Использовать текущий клиентский расчёт итоговых значений.

## Поведение и приёмка

Каждая строка атаки показывает итог и разбивку в формате «830 (810 +20)». Бонус выделяется зелёным, как на скриншоте. При нулевом бонусе выводится только значение атаки. Скорость атаки оформляется по-прежнему.

## Проверки

Собрать и установить пакет интерфейса. В клиенте сравнить оружие одного шаблона без заточки и с заточкой, проверить обе строки и совпадение итога с суммой.

## Допущения и открытые вопросы

Скрытие нулевого бонуса принято для компактности. Открытых вопросов для реализации нет.
