# Навык иконок оружия с ЛС

Цель — сохранить принятый способ подготовки иконок 32×32 для следующих задач. Создать личный навык с исходником в tools/skills, эталонными парами и принятым PNG-превью.

Поведение — искать штатные альтернативы, редактировать исходную иконку через ImageGen по эталону, проверять размер и результат клиентского сжатия. Установка в клиент выполняется в пределах запроса пользователя.

Приёмка — валидный SKILL.md, доступные изображения, установка в личный каталог навыков. Принятое художественное превью требует отдельной подготовки точных текстур 32×32 перед использованием в игре. Открытых вопросов нет.
