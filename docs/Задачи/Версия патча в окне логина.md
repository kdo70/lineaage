# Версия патча в окне логина

Цель — показывать версию установленного патча до входа в игру.

- Область — клиентское окно логина.
- Подпись в правом верхнем углу в формате «Версия X.Y.Z», начальное значение — «Версия 2.120.982».
- Приёмка — подпись видна до авторизации, читается и не перекрывает элементы входа.
- Проверки — загрузка клиентского ресурса и расположение на нескольких разрешениях.

Предположение — угол относится ко всему экрану входа. Открытых вопросов нет.

В `client-patch/system/interface.xdat` добавлена подпись для `LoginState` с правой верхней привязкой, чтобы версию сборки можно было проверить до авторизации. Установка выполняется заменой `system/interface.xdat` при закрытом клиенте.

Повторное чтение XDAT подтвердило текст и привязку. Визуальная проверка остаётся открытой из-за ошибки Windows при запуске клиента.
