# Перенос сцены входа

Цель — вернуть пользовательскую сцену старого клиента вместе с музыкой и звуковыми эффектами.

- Границы — ресурсы экрана входа рабочего клиента client/build.
- Ожидаемое поведение — до авторизации воспроизводятся сцена и её звуки, форма входа работает.
- Приёмка — изображение, движение камеры и звук соответствуют старому клиенту.
- Проверки — сравнить ресурсы и зависимости, проверить запуск и воспроизведение.

Предположение — рабочая поставка находится в client/build. Открытый вопрос — состав аудиоресурсов сцены.

В рабочий клиент перенесены карта Lobby.unr, модели l2_lobby.usx и текстуры L2_Lobby_T.utx, чтобы восстановить сцену входа. В секции [LobbySound] файла alaudio.int выбран LogInSound=NS04_F. Трек music/ns04_f.ogg и фоновые звуковые пакеты уже входят в клиент.

Для установки скопировать папки maps, staticmeshes, textures и system из client-patch поверх клиента при закрытой игре, затем запустить клиент. Ресурсы сверены с донором по SHA-256. В alaudio.int проверена точечная замена трека входа.
