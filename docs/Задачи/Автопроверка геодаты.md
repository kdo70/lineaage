# Автопроверка движения по регионам

Цель — найти по серверной геодате места, где движение по метке останавливается, хотя рядом есть проходимый маршрут. Проверить каждый установленный регион на воспроизводимой выборке возле препятствий. Критерий — координаты и проверенный маршрут для каждого найденного случая, число проверок по регионам. Геометрия экрана, динамические двери и фактические клики клиента остаются за границами моделирования.
