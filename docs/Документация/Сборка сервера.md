# Сборка сервера

## Структура

- `D:\Lineage\source` — неизменяемый оригинал.
- `D:\Lineage\build\aCis_gameserver` — рабочий Java-код и конфигурация.
- `D:\Lineage\build\aCis_datapack` — рабочие игровые данные и SQL.
- `D:\Lineage\build\dist` — собранный комплект сервера.

## Требования

JDK 21+ и Apache Ant. На текущем компьютере установлены JDK 21.0.12 и Ant в `C:\apache-ant-1.10.17`.
Переменная `JAVA_HOME` указывает на JDK; `ant.bat` доступен в PATH.

## Команда

```powershell
cd D:\Lineage\build
.\compile.ps1
```

Скрипт компилирует Java с release 21 и UTF-8, затем собирает datapack.
Зависимости берутся из локальной папки `aCis_gameserver\lib`.
Ожидаемый результат: `BUILD SUCCESSFUL` и комплект в `dist`:

- `login` — LoginServer, библиотеки и конфигурация.
- `gameserver` — GameServer, библиотеки, конфигурация и data.
- `sql` — SQL для базы данных.
- `tools` — инструменты datapack.

## Повторная сборка

В рабочей копии исправлены проверка версии JDK и параметры компиляции.
Копирование `serverNames.xml` из datapack выполняется без удаления остальных файлов LoginServer: исходный `sync` заменён на `copy`.

Изменяй файлы в рабочих проектах, затем выполняй команду снова.
Промежуточные классы очищаются; содержимое datapack синхронизируется в dist.
Для запуска с сохранением рабочих данных выделяем отдельный runtime-каталог на этапе локальной настройки.

## Проверка оригинала

После копирования сверены SHA-256 всех 18174 файлов оригинала с `build\source-baseline.json`: изменений нет.

## Запуск

Среда Docker уже настроена. Первый запуск, обновление контейнеров и работа с данными описаны в [[Локальная среда Docker]]. Компиляция не заменяет проверку запуска и игровых механик.
