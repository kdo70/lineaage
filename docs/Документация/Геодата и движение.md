# Движение по метке

При наземном щелчке игрок обходит небольшие препятствия и может выйти из угла. Для близкой метки на полу (до 1024 единиц) сервер проверяет маршрут с запасом длины до 512 единиц. Поиск ограничен 2048 итерациями и настройкой MaxIterations. Каждый отрезок проверяется по геодате.

Если метка недоступна, сервер ищет достижимую точку в направлении щелчка, при необходимости с коротким шагом вдоль стены. Для обычного перемещения дальность команды проверяется также от позиции игрока на сервере. На тестовом сервере TRACE_GM_CLICKS=true записывает координаты щелчков GM и результат маршрута.
