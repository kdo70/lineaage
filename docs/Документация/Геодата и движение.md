# Геодата и движение по метке

Итог работ на 25 ноября 2026 года. Цель — дать игроку пройти к доступной метке у стены, обогнуть препятствие и подняться по ступеням. На сервере изменены два тестовых региона L2J и обработка наземного щелчка.

## Изменения карты

| --- | --- | --- |

| Talking Island, 17_25 | На лестницах памятника персонаж останавливался на второй ступени или начинал обход. | По фактическим щелчкам из журнала найдены закрытые переходы внутри ступеней и на площадку. На четырёх лестничных маршах открыты 62 направления в 34 клетках. |

Оба файла получены локальной правкой исходных регионов L2J. Высоты и слои сохранены. Генерация карты из клиентской геометрии и исправление провалов под текстуры остаются за пределами подтверждённого результата. Тестовая конфигурация подключает файлы из `build/geodata-test` через `build/compose.gludio-test.yaml`; исходные регионы хранятся в `build/geodata`.

## Движение игрока

При щелчке по доступному полу сервер сначала проверяет прямой проход. Если путь перекрыт, для метки в пределах 1024 мировых единиц он ищет обход с запасом длины до 512 единиц. Поиск ограничен меньшим из двух значений — 2048 итераций и `MaxIterations`. Сервер проверяет каждый отрезок по геодате.

Для недоступной метки сервер подбирает достижимую точку в направлении щелчка. У стены допустим короткий шаг в сторону прохода. Дальность команды дополнительно проверяется от серверной позиции игрока. На тестовом сервере `TRACE_GM_CLICKS=true` записывает координаты щелчка GM, выбранный маршрут и заблокированный шаг. Исправлена ошибка этой диагностики, которая прерывала движение при свободном пути.

## Проверки и ограничения

- **В игре** пользователь подтвердил улучшение бега и обхода препятствий. Для последней версии четырёх лестниц отдельного подтверждения в клиенте нет.
- **У памятника** семь маршрутов проверены на подъём и спуск с разным размером шага. Проверка коллизии основания памятника прошла. Журнал Bartz также зафиксировал подъём на площадку до Z = −3704.
- **По всем 139 регионам** проверена одна воспроизводимая выборка из 372 835 щелчков. До изменения обхода найдено 116 случаев, когда игрок продвигался меньше одной клетки при наличии проверенного пути с одним поворотом. При повторе на той же выборке таких случаев было 0. Прогон предшествовал последней правке лестниц. Геометрия клиента и динамические двери требуют отдельной проверки. [Результаты и таблицы по регионам](../Задачи/Результаты%20автопроверки%20геодаты.md)
