# Выдача всего списка оружия

В GM Shop → Weapons рядом с каждой из 20 категорий добавлена All, чтобы выдать себе все продукты мультиселла для тестирования. Количество берётся из production, всё оружие выдаётся +16; щиты сохраняют исходную заточку. Ингредиенты не расходуются, выбранная цель предметов не получает. Открытие обычного мультиселла остаётся по ссылке количества.

Команда `admin_buy all gm_weapon_...` требует права `admin_buy`, административного списка без NPC-привязки. До выдачи проверяются все продукты, суммарные места и вес, переполнение количеств. При нехватке места/веса выдача не начинается. Выдача запрещена во время обмена/магазина, результат записывается в лог. При неожиданном отказе добавления возможен частичный результат: сообщение сообщает число выданных предметов, автоматически повторять операцию нельзя.

Код: `AdminAdmin.java`, `AdminWeaponGrant.java`; страница `data/html/admin/gmshop/Weapons.htm`. Количество и All находятся в отдельных ячейках одной строки, ширина таблиц 270 пикселей. Установлено на локальный сервер. Пройдены сборка, 13 проверок планирования выдачи, включая список из 116 строк, стопки и переполнение; сверены 20 кнопок и XML. Пользователь принял результат. После подтверждения проверены права, ограничение GM-списками, выдача только себе и арифметические границы; новых уязвимостей в проверенном коде не выявлено.
