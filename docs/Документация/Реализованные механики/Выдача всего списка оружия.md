# Выдача всего списка оружия

Кнопка All в GM Shop → Weapons бесплатно выдаёт администратору по одному предмету из выбранной категории для тестов. Оружие выдаётся с заточкой +16. Buy открывает штатное окно покупки. Обе кнопки сохраняют открытую страницу Weapons, чтобы можно было продолжить работу с выбранным грейдом или Special. Qty показывает число позиций в списке покупки.

Команда `admin_buy all weaponBuyListId` требует права `admin_buy` и списка с признаком `gmWeapon`. Перед выдачей проверяются активность обмена и магазина, свободные места, вес и пределы количеств. Результат записывается в журнал. При отказе добавления сервер сообщает, сколько предметов уже выдано.
