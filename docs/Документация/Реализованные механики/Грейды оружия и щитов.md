# Грейды оружия и щитов

Оружие и щиты получают боевые характеристики эталона своего типа и грейда, чтобы выбор модели сохранялся при переходе к следующему грейду. Оригиналы сохраняют ID. Копии сохраняют название и текстуры и получают отдельный ID для каждого грейда выше исходного до S.

GM Shop → Weapons открывает NG. Верхняя строка переключает грейд и открывает специальные категории. Списки бесплатны и доступны по праву admin_buy. Кнопка All выдаёт оружие с заточкой +16. Щиты на витрине уникальны по текстуре в пределах грейда.

Иконки вариантов зарегистрированы в itemIcons.xml для окна Камня жизни. Для стандартных эффектов c_u000–c_u008 индекс в weapongrp синхронизирован с ресурсом каждого слота, чтобы отображалась аугментация. Исходные исключения сохранены. Свечение проверено в игре на Scroll of Wisdom и Heathen’s Book. Для массовой правки проверена обратная сборка DAT; игровая проверка парного оружия ещё открыта.
