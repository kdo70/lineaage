# Каталог оружия и щитов

Каталоги сервера и клиента очищены и согласованы, чтобы убрать недоступные предметы и повторные точки выдачи. Итоговые операции перечислены в [[Задачи/Итоговая таблица оружия и щитов.tsv|таблице ID]].

GM Shop → Weapons открывает списки по типу и магическому признаку. NPC, Infinity, Event, щиты, питомцы и удочки доступны отдельно. Питомцам доступны 33 серверных шаблона, удочкам — все шесть грейдов. Для них повтор текстуры допустим. Служебные ID с разными свойствами сохранены по карте решений.

GM-списки помечены adminOnly. Право admin_buy проверяется при открытии и покупке. После открытия мультиселла повторно отправляется страница Weapons. NPC-оружие исключено из обычных источников выдачи, ему запрещены передача, выбрасывание и продажа.

Удалены розничные СА, теневое и купонное оружие, Elrokian Trap и связанные обмены/выдача. Миграции tools/weapon-catalog/migrate.sql и refine.sql применяются при остановленной игре после резервного копирования. СА переводятся на базу с сохранением object_id и заточки; аугментация хранится отдельно.

Lizardspear имеет тип POLE, хват lrhand и иконку monster. Great Sword 1299 перенесён в NPC-оружие. Ограничения set должны стоять перед for/cond: обратный порядок отклонял 67 шаблонов и вызывал ошибку восстановления сохранённой вещи. Порядок исправлен и проверен по всем XML предметов.

Проверены сборка, обратная сборка DAT, повторная миграция на копии БД, отсутствие выбывших ID и права GM-мультиселлов. Поведенческие проверки выполнены пользователем в игре. Исходные DAT находятся в client/source, рабочие — в client/build, поставляемые изменения — в client-patch/system.
