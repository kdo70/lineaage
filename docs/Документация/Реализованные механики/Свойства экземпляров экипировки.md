# Свойства экземпляров экипировки

Экземпляр предмета хранит титул и сведения о первом владельце. Для экипировки дополнительно задаются цвет названия и до десяти умений. Это позволяет настраивать разные экземпляры одного шаблона.

- Панель GM **Equipment** (`//equipment`) позволяет задать и сбросить титул и RGB-цвет, добавить и удалить умения и изменить заточку. Повторное добавление того же ID меняет уровень. Умения действуют при надевании предмета.
- Подсказка показывает тип, название, уровень, иконку и описание умения. Первое получение предмета записывает имя персонажа и дату по времени Томска. Передача предмета, переименование или удаление персонажа сохраняют исходную запись. Для старых предметов без сведений блок владельца скрыт.
- Сервер добавляет поля в `items` и `items_on_ground` при запуске. Клиент использует `client-patch/system/interface.u`. Изменённые исходники UnrealScript лежат в `client-patch/source`.
