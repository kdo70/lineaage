# Локальная среда Docker

## Состав

Настройки среды находятся в `D:\Lineage\build\compose.yaml`, скрипты — в `build\docker`.
Оригинал `source` не используется как рабочий каталог и не изменяется.

- `db`: MariaDB 11.4, база `acis`, пользователь `acis`, порт `127.0.0.1:3306`.
- `login`: LoginServer, клиентский порт `127.0.0.1:2106`.
- `game`: GameServer, клиентский порт `127.0.0.1:7777`.
- Внутренний порт 9014 доступен между контейнерами и не опубликован на Windows.

GameServer сообщает клиенту адрес `127.0.0.1`; среда рассчитана на клиент на этом же компьютере.

В рабочем `build/aCis_gameserver` исправлен выбор адреса в пакете `ServerList`: используется объявленный GameServer адрес (`Hostname`). Прежняя подмена для локальных IP на адрес соединения GameServer с LoginServer выдавала клиенту внутренний IP Docker и мешала пройти выбор сервера. После изменения Java-кода требуется пересборка образа.

## Требования

Docker Desktop с Linux containers и WSL 2, включённая аппаратная виртуализация.
После установки компонентов Windows может потребоваться перезагрузка.
Перед запуском `docker info` должен успешно показывать секцию Server.

## Первый запуск

```powershell
cd D:\Lineage\build
.\docker\init-env.ps1
.\compile.ps1
docker compose config --quiet
docker compose up -d --build
docker compose ps
docker compose logs --tail 100 login game
```

Скрипт создаёт `.env` со случайными локальными паролями и идентификатором регистрации сервера; существующий файл не перезаписывает.
Не публикуй `.env`. Его содержимое используется и для подключения приложений, и для инициализации БД.
Java-код компилируется на Windows через `compile.ps1` (JDK 21 и Ant); Docker упаковывает `build\dist` в образ с JRE 21.
Для сборки и запуска одной командой используй `D:\Lineage\build\dev-up.ps1`.
Для первой сборки требуется интернет.

При создании пустого DB volume импортируются SQL из рабочего datapack, затем регистрируется сервер 1.
Существующая база при обычном повторном запуске не импортируется и не очищается.
Не меняй пароли и GAME_HEX_ID в `.env` после инициализации без соответствующего обновления БД.

## Ежедневная работа

```powershell
cd D:\Lineage\build
docker compose up -d
docker compose logs -f login game
docker compose stop
```

После изменения Java-кода, конфигурации или datapack:

```powershell
 .\compile.ps1
docker compose up -d --build login game
```

Правки SQL не применяются автоматически к существующей БД; изменения схемы требуют отдельного импорта или миграции.
Не храни единственную копию новых файлов внутри контейнеров: редактируй рабочие проекты в `build`.
Логи и эмблемы кланов сохраняются в отдельных volumes. Другие новые файлы, создаваемые вручную внутри контейнера, переноси в рабочие исходники: пересоздание контейнера удаляет его временные файлы.

## Данные и остановка

`docker compose down` удаляет контейнеры и сеть, сохраняя volumes с базой и логами.
Не добавляй `-v`: этот флаг удаляет volumes, включая базу.
Пароли для подключения внешнего клиента БД находятся в `build\.env`; адрес — `127.0.0.1`, порт — 3306, база и пользователь — `acis`.

Для запуска скопированы 139 файлов L2J-геоданных (около 554 МБ) из `C:\a1_l2j\build\gameserver\data\geodata` в `D:\Lineage\build\geodata`.
Каталог подключён к GameServer отдельно от образа; entrypoint устанавливает `GeoDataType = L2J`.
Оригинальный datapack не содержал обязательных геоданных, и без них GameServer завершался.
Найденные геоданные позволили загрузить сервер; точность движения и геометрии требует проверки клиентом.
В логе остаются предупреждения высоты двух территорий спавна: `aden09_2518_09` и `gludio01_qm1821_02`.
Если текущая сессия PowerShell была открыта до установки Docker, добавь его инструменты в PATH этой сессии:

```powershell
$env:PATH = 'C:\Program Files\Docker\Docker\resources\bin;' + $env:PATH
```

Готовность MariaDB проверяется штатным healthcheck, LoginServer — портом 9014, GameServer — портом 7777.
Проверка открытого порта не заменяет вход игровым клиентом и проверку логов.
Ограничения текущего datapack, в том числе отсутствие геоданных, проверяются отдельно при старте.
