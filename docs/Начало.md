# Lineage II Interlude

## Навигация

- [[Документация/Индекс|Документация]] — сборка, локальная среда и реализованные механики.
- [[Идеи/Индекс|Идеи]] — предложения, которые ещё не являются утверждённой спецификацией.

- [[Задачи/Индекс|Задачи]] — технические задания и критерии приёмки.

Планы создавай по необходимости; шаблоны находятся в папке `Шаблоны`.

## Правила ведения

- Вся документация хранится только в `D:\Lineage\build\docs`. Рабочий код и данные находятся в `build`, оригинал — в `source`.
- У каждой реализованной механики должен быть один основной документ: поведение, настройка, проверка и ограничения. Результаты проверок добавляй туда с датой и границами проверки.
- При изменении функциональности обновляй соответствующий документ и его дату обновления. Новые документы добавляй в индекс.
- Различай реализованное поведение, предложение и результат проверки. Успешная сборка и статус контейнера не подтверждают работу механики в клиенте.
- Идея описывает предложение, задача — проверяемый результат, план — последовательность работ. Для небольшой задачи достаточно плана внутри задачи.
- Даты записывай как `ГГГГ-ММ-ДД`; приоритеты задач: `высокий`, `средний`, `низкий`.
- Не сохраняй пароли, токены и приватные ключи в документации.

Шаблоны можно копировать вручную или вставлять через Obsidian Templates. Используй ссылки `[[Название заметки]]`; вложения сохраняй внутри `docs`.
