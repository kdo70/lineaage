# Офлайн-торговля

Перенесена из `C:\a1_l2j`. Приватные лавки покупки, продажи, пакетной продажи и крафта остаются в мире после отключения клиента.

## Использование

1. Открыть лавку в мирной зоне.
2. Ввести `.offline` либо отключиться с открытой лавкой.
3. Можно снова войти в аккаунт другим персонажем. Вход тем же персонажем закрывает его офлайн-лавку и возвращает управление.

При переходе в офлайн персонаж выходит из группы и комнаты поиска группы, снимает регистрацию на Олимпиаду, убирает питомца и прирученного зверя. Режим недоступен на Олимпиаде, фестивале, в тюрьме и на корабле.

## Настройки

Файл: `aCis_gameserver/config/mods/offlineshop.properties`. Изменения требуют перезапуска.

| Параметр | Значение в сборке | Назначение |
| --- | --- | --- |
| OfflineTradeEnable | True | Офлайн-покупка и продажа |
| OfflineCraftEnable | True | Офлайн-крафт |
| OfflineModeInPeaceZone | True | Только мирные зоны |
| OfflineModeNoDamage | True | Защита офлайн-лавки от урона |
| OfflineSetNameColor | True | Менять цвет имени |
| OfflineNameColor | 808080 | Цвет имени в hex |
| RestoreOffliners | True | Сохранение и восстановление лавок |
| OfflineMaxDays | 10 | Срок восстановления; 0 — без ограничения |
| OfflineDisconnectFinished | True | Удалять персонажа из мира после завершения торговли |

Срок проверяется при запуске сервера, а не таймером во время работы.

## База данных и запуск

Схемы `aCis_datapack/sql/character_offline_trade.sql` и `character_offline_trade_items.sql` создают таблицы состояния лавок и их товаров/рецептов. Они включены в установщики БД; Docker применяет SQL автоматически только при первичной инициализации пустой БД. Для существующей БД применить обе схемы вручную перед запуском нового ядра.

Сохранение выполняется при штатном выключении через `Shutdown`, до отключения игроков. Восстановление выполняется после спавна мира через `OfflineTradersTable`; после загрузки таблицы снимка очищаются. Аварийное завершение не гарантирует восстановления лавок.

## Проверка

Полная сборка: `ant -f build.xml` из корня репозитория. Проверены успешная компиляция, применение схем и запуск Docker-сервисов; в журнале появились `Offline traders`, `Loaded 0 offline trader(s)` и регистрация GameServer на LoginServer. Игровые сценарии проверяются вручную: `.offline`, покупка у отключённого продавца, повторный вход, закрытие распроданной лавки и восстановление после штатного рестарта.
